# Azure RM Terraform Modules

A collection of reusable Terraform modules for provisioning and managing Azure cloud infrastructure resources using the AzureRM provider.

## Overview

This repository contains a set of standardized, reusable Terraform modules that help you provision and manage various Azure resources in a consistent and efficient manner. These modules encapsulate best practices and can be easily integrated into your Infrastructure as Code (IaC) workflows.

## Prerequisites

- Terraform >= 0.12.x
- Azure CLI
- Azure Subscription
- Service Principal with required permissions

## Module Documentation

Each module includes:

- `main.tf` - Main resource definitions
- `variables.tf` - Input variables
- `output.tf` - Output values

Refer to individual module directories for specific documentation and usage examples.
